Project Vision: Web 1.0 Site Generator

The goal of this project is to create a utility that generates complete, "period-accurate" Web 1.0 websites. The objective is to make launching a customized, distinct website as low-friction as possible for users—easier than setting up a social media profile.
Core Technical Constraints (CRITICAL)

Jules must strictly adhere to these rules to ensure period-accuracy:

    Target Standards: HTML 3.2, 4.0, or 4.01 Transitional.

    No Modern CSS: Avoid Flexbox, Grid, or modern CSS variables.

    Layout Methods: Use <table> based layouts and <frameset> structures.

    Styling: Lean on HTML attributes for styling (e.g., bgcolor, align, valign, border) and basic inline CSS where appropriate for the late 90s era.

    Asset Compatibility: Design for low-bandwidth "dial-up" aesthetics. Use standard web-safe fonts (Times New Roman, Arial, Courier).

Functional Requirements

The generator should eventually allow users to configure:

    Site Type: Personal homepages, webcomic repositories, "book-style" informational sites.

    Layouts: Classic sidebar (frames), top-nav (tables), or centered "under construction" splash pages.

    Customization: User-defined color schemes (hex codes or standard names), page counts, and resource links.

    Portability: The output must be a clean ZIP or folder structure ready for immediate upload to services like Neocities.

Aesthetic Persona

The generated sites should feel "Pure Web"—vibrant, unique, and personal. Think tiled backgrounds, GIF-heavy navigation, and visible table borders. This project is a tribute to the early internet; avoid "clean/minimalist" modern design trends unless specifically requested.
